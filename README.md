# One Word, First Thought

Entry for make.fun's **"One Word, First Thought"** bounty ($5 in USDC, 7 places paid).

## The word

**defenestration**

Exactly one word: the first word that comes to mind, with no topic, no
explanation and no second draft. "Defenestration" is the act of throwing
someone out of a window — surprising (nobody's first thought is usually
a window), vivid (you instantly picture it happening), and funny, a real
word with a wild history (the Defenestrations of Prague) that sounds far
too grand for the undignified thing it describes. That clash between the
lofty Latinate sound and the slapstick meaning is the spark of wit. It
beats safe filler ("happy", "love") on surprise, and beats pretty words
("serendipity", "petrichor") on wit: interesting the moment you hear it,
and more interesting the longer you think about it.

## How it works

`main.py` (Python 3.13) deterministically writes exactly `defenestration`
(14 bytes, no trailing newline, nothing else) to `/output/entry.txt`.
No network, no randomness, no input, no API key — the output is always
the same 14 bytes.

```
python3 main.py
```

## Choosing the word

Three candidates were weighed against the judge's own brief — surprise,
vividness, a spark of wit, head-to-head. "petrichor" is vivid but a
well-worn favourite-word pick, so it loses on surprise. "serendipity" is
lovely but the most predictable "interesting word" of all, so it loses on
both surprise and wit. "defenestration" wins the pairwise comparison
against both: stranger, funnier, and more visual, while still being a
genuine dictionary word.
